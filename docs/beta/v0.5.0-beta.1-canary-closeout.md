## Current Rust/Cargo Beta Path

The published `v0.5.0-beta.1` binary can run workflow YAML files by path. For
Rust crate work during this beta, use the repo-hosted Cargo workflow file:

```sh
git clone https://github.com/uesugitorachiyo/ao2.git
cd ao2
git checkout 87c4cbe9706ea7d1721eaadcdb50e816cc96e91f

ao2 run examples/task-templates/rust-cargo-bug-fix.yaml \
  --target /path/to/rust-crate \
  --provider codex \
  --provider-prompt-file prompt.txt
```

Use `cargo test` as the verifier for Rust beta runs. Do not use the default
Python `bug-fix` template for Rust projects unless that Rust project is
intentionally driven by pytest.

AO2 binaries built from commit `87c4cbe9706ea7d1721eaadcdb50e816cc96e91f` or
newer can also expose the template through `ao2 template list` and
`ao2 template show rust-cargo-bug-fix`. The already-published
`v0.5.0-beta.1` binary was built earlier, so this closeout only claims the
workflow-by-path path for that binary.

## Boundary

repositories, create pull requests, publish releases, upload assets, deploy
services, or contact external users.
