# AO2 v0.5.13 Stable Patch Release Notes

AO2 `v0.5.13` adds a shared software-source growth policy to SDD planning and
agent-backed SDD execution. AO2 Control Plane `v0.1.19` remains the compatible
observer release; this patch does not change its read-only authority boundary.

## Changes Since v0.5.12

- SDD provider requests now carry `context.software_source_policy`, requiring
  destination-repository inspection before planning source changes.
- Agent-backed SDD execution receives the same policy, so implementation stops
  at the first sufficient choice: no change, reuse or deletion, standard
  library or native platform, an already-installed dependency, or the smallest
  cohesive source change.
- Generated and vendored source remains classified as source and requires an
  explicit reviewable exception from handwritten-source limits.
- Documentation, evidence, logs, reports, manifests, non-executable fixtures,
  and other non-source artifacts remain outside the source-growth policy.
- Language-specific thresholds and deterministic checks remain owned by the
  destination repository and bind through AO2's exact staged or base/head
  quality snapshots.

AO2 does not add a universal language parser, source threshold, dependency, or
architecture engine. Cohesion remains a model-review judgment, while objective
facts remain repository-native verifier work. Trust-boundary validation,
security controls, accessibility, required compatibility, and data-loss
prevention are not subject to simplification pressure.

## Verification

The patch is covered by the SDD provider-envelope contract, the ten
representative source/non-source cases, AO2 exact-snapshot quality tests, the
Rust architecture ratchet, the full workspace verification gate, and hosted
pull-request CI.

Publication remains gated by the existing release-readiness, provenance,
three-platform archive smoke, installation, rollback, and final-closure
contracts. These notes do not create a tag, release, deployment, promotion, or
provider authority.
