# AO2 v0.5.0 Stable Release Notes

AO2 `v0.5.0` is the current stable public release.

Release URL: <https://github.com/uesugitorachiyo/ao2/releases/tag/v0.5.0>

Compatible stable companion:
[AO2 Control Plane v0.1.15](https://github.com/uesugitorachiyo/ao2-control-plane/releases/tag/v0.1.15).

## Public Assets

The release publishes archives for:

- macOS aarch64
- Linux x86_64
- Linux aarch64
- Windows x86_64

The public asset set also includes `SHA256SUMS`, CycloneDX SBOMs, detached
signatures, signed provenance, release readiness JSON, and release-train bridge
evidence.

## Verification

Before installing, download the release assets and run:

```sh
shasum -a 256 -c SHA256SUMS
```

After extracting the archive, run `./verify-release.sh` on macOS/Linux or
`.\Verify-Release.ps1` on Windows. Then install and confirm:

```sh
ao2 version --json
ao2 doctor --json
```

See [Install And Update Guide](../INSTALL.md) and
[Public Release Verification](PUBLIC-RELEASE-VERIFICATION.md) for the operator
workflow.

## Boundaries

AO2 remains local-first. The stable release does not grant release approval
authority to the control plane, does not require provider API keys for the
first-run path, and does not publish external pilot results.
