# AO2 v0.5.4 Stable Patch Release Notes

AO2 `v0.5.4` is a stable patch release for the AO2 `v0.5` release line.

Release URL: <https://github.com/uesugitorachiyo/ao2/releases/tag/v0.5.4>

Compatible stable companion:
[AO2 Control Plane v0.1.18](https://github.com/uesugitorachiyo/ao2-control-plane/releases/tag/v0.1.18).

## Why This Patch Exists

AO2 `v0.5.3` introduced the canonical five-asset hosted release contract, but
`ao2 doctor` still expected the previous private-release sidecar layout. That
made doctor report false release failures for valid hosted binaries.

## Included Changes

- `ao2 doctor` recognizes the exact hosted publication inventory: native
  Linux x86_64, macOS aarch64, and Windows x86_64 archives together with
  `promotion-plan.json` and aggregate `SHA256SUMS`.
- Hosted release checks validate every aggregate checksum and bind archive
  digests to the promotion plan.
- Promotion plans must match the requested tag and version, carry a valid
  source commit and physical-Windows evidence digest, and preserve the exact
  hosted trust and Windows-equivalence boundaries.
- Legacy signed private-release bundles retain their existing doctor path.
- Regression fixtures reject altered archives and malformed or mismatched
  hosted release metadata.

## Qualification

The candidate is qualified only when the release workflow produces native
macOS, Linux, and Windows archives from the exact merged source commit, the
outbound-only physical Windows lifecycle passes, and the immutable hosted
promotion plan binds all resulting digests.

## Boundaries

Qualification included a successful no-publication dry run before the
environment-gated live workflow. The release grants no execution authority to
the Control Plane, changes no credentials, and does not authorize broad RSI.
