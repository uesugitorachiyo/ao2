# AO2 v0.5.0-beta.1 External Beta

AO2 v0.5.0-beta.1 is an external beta, not AO2 1.0. AO2 v0.4.81 remains the
latest stable release. This beta is qualified with AO2 Control Plane v0.1.15.

## Supported Platforms

- macOS arm64
- Linux arm64
- Linux x86_64
- Windows x86_64

## Changes Since v0.4.81

- Approval records bind the approved bytes, policy context, and base commit.
- Replay rejects stale approval, policy, and repository state.
- Sandbox mutation requires an explicit approval identity and bounded patch
  metadata.
- Dry-run packets include rollback receipts and operator review evidence.
- Release archives report the packaged commit and contain CycloneDX SBOM,
  license, notice, checksum, installer, and verification material.
- Evidence migration checks preserve compatibility with v0.4.81 run records.

## Install And Verify

Download the archive for your platform, `SHA256SUMS`, its checksum and signature
sidecars, the release provenance files, and the signing public key. Verify the
download before extracting it:

```sh
shasum -a 256 -c SHA256SUMS
tar -xzf ao2-0.5.0-beta.1-<platform>.tar.gz
./verify-release.sh
./install.sh
ao2 version --json
ao2 doctor --json
```

On Windows, use `Verify-Release.ps1` and `install.ps1` from the archive.

## Upgrade And Rollback

After verifying the beta archive and provenance:

```sh
ao2 install update --archive ao2-0.5.0-beta.1-<platform>.tar.gz
ao2 install rollback
```

Rollback restores the previous installed binary. To return explicitly to
v0.4.81, download and verify the v0.4.81 archive and run its installer.

## Uninstall

Remove `ao2`, `ao2.rollback`, and `ao2.install-verification.json` from the
installation directory. See `docs/INSTALL.md` for platform-specific paths and
PowerShell commands. Repository-local run evidence is not removed.

## Known Limitations

- This is a beta channel and is not selected by stable update checks.
- Live provider pilots remain disabled during publication and require separate
  explicit opt-in during execution.
- AO2 Control Plane observes evidence; it does not approve or execute work.
- Release publication requires operator authorization and production signing
  material outside the repository.
- RSI remains denied.
