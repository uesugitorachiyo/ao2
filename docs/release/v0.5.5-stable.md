# AO2 v0.5.5 Stable Patch Release Notes

AO2 `v0.5.5` is a stable patch release for the AO2 `v0.5` release line.

Release URL: <https://github.com/uesugitorachiyo/ao2/releases/tag/v0.5.5>

Compatible stable companion:
[AO2 Control Plane v0.1.18](https://github.com/uesugitorachiyo/ao2-control-plane/releases/tag/v0.1.18).

## Why This Patch Exists

AO2 `v0.5.4` accepted the canonical five-asset hosted release contract when
release assets were supplied explicitly, but a clean archive install could
still report `doctor.status=attention` when checkout-local private provenance
was absent.

## Included Changes

- `ao2 doctor` accepts strict verified install evidence from the packaged
  archive when no explicit release check is requested.
- Install evidence must match the running AO2 version and target and must bind
  verified offline checksum coverage.
- Explicit release checks continue to require their release assets and
  provenance contract.
- Hosted post-stable verification installs into an isolated platform-default
  home, places the binary on `PATH`, and requires `doctor.status=ok`.
- Stable-promotion evidence collectors validate the archive-native install and
  doctor evidence instead of removed private-release sidecars.

## Qualification

The release was qualified with native macOS, Linux, and Windows archives built
from the exact merged source commit, a passing outbound-only physical Windows
lifecycle, and a hosted dry run binding every archive and physical evidence
digest.

## Boundaries

Qualification included a successful no-publication dry run before the
environment-gated live workflow. The release grants no execution authority to
the Control Plane, changes no credentials, and does not authorize broad RSI.
