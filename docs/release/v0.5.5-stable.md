# AO2 v0.5.5 Stable Patch Release Notes

AO2 `v0.5.5` is the next qualified patch candidate for the AO2 `v0.5`
release line. Publication remains gated by the hosted release workflow and is
not implied by this document.

Compatible stable companion:
[AO2 Control Plane v0.1.18](https://github.com/uesugitorachiyo/ao2-control-plane/releases/tag/v0.1.18).

## Why This Patch Exists

AO2 `v0.5.4` accepts the canonical five-asset hosted release contract when
release assets are supplied explicitly, but a clean archive install can still
report `doctor.status=attention` when checkout-local private provenance is
absent.

## Included Changes

- `ao2 doctor` accepts strict verified install evidence from the packaged
  archive when no explicit release check is requested.
- Install evidence must match the running AO2 version and target and must bind
  verified offline checksum coverage.
- Explicit release checks continue to require their release assets and
  provenance contract.
- Hosted post-stable verification installs into an isolated platform-default
  home, places the binary on `PATH`, and requires `doctor.status=ok`.
- Stable-promotion evidence collectors validate the archive-native install and
  doctor evidence instead of removed private-release sidecars.

## Qualification

The candidate is qualified only when native macOS, Linux, and Windows archives
are built from the exact merged source commit, the outbound-only physical
Windows lifecycle passes, and the hosted dry run binds all archive and physical
evidence digests.

## Boundaries

Qualification creates no tag or release, uploads no public asset, grants no
execution authority to the Control Plane, changes no credentials, and does not
authorize broad RSI.
