# AO2 v0.5.9 Stable Patch Release Notes

AO2 `v0.5.9` adds strict offline repair qualification and clearer repair
failure classification while preserving the local-first policy and
side-effect boundaries from `v0.5.8`. AO2 Control Plane `v0.1.19` remains
the supported companion release.

## Changes Since v0.5.8

- Adds a strict `repair_qualified` or `repair_rejected` verdict over
  digest-bound source, reproduction, regression, review, and candidate
  evidence.
- Classifies repair failures without consulting issue discussions, known
  fixes, Git history, credentials, providers, or the network.
- Rejects malformed, stale, mismatched, linked, oversized, or unsafe
  qualification evidence before accepting a candidate.
- Projects qualification results through credential-free operator readbacks
  and current compatibility fixtures.

## Supported Archives

- macOS aarch64
- Linux x86_64
- Windows x86_64

Linux aarch64 hosts may use the Linux x86_64 archive under explicit Docker
emulation. AO2 `v0.5.9` does not publish a Linux aarch64 archive.

Verify the downloaded archive against `SHA256SUMS` before installation. The
credential-free fixture replay remains available for local evaluation.
Rollback uses `ao2 install rollback`; AO2 Control Plane remains a read-only
observer and does not approve or publish AO2 releases.
