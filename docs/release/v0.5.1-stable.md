# AO2 v0.5.1 Stable Patch Release Notes

AO2 `v0.5.1` is a stable patch release for the AO2 `v0.5` line.

Release URL: <https://github.com/uesugitorachiyo/ao2/releases/tag/v0.5.1>

Compatible stable companion:
[AO2 Control Plane v0.1.15](https://github.com/uesugitorachiyo/ao2-control-plane/releases/tag/v0.1.15).

## Why This Patch Exists

AO2 `v0.5.0` was the first stable public release. After that tag, several
post-stable reliability fixes landed on AO2 `main`. AO2 `v0.5.1` publishes
those fixes in stable public binaries without starting a new feature train.

## Included Reliability Fixes

- Windows rollback safety:
  - Windows active installed-binary self-rollback is blocked before AO2 tries
    to overwrite the running `ao2.exe`.
  - AO2 prints `rollback_status=blocked_active_executable` with a clear
    Windows-safe recovery path.
  - Windows operators should run rollback from an extracted or alternate
    `ao2.exe` runner from the verified archive.
- Windows release smoke target initialization:
  - The Windows release smoke target is initialized as a Git repository before
    workflow smoke checks run.
- Approval and replay diagnostics:
  - Operator-facing output includes clearer approval status, action digest,
    replay state, and recovery guidance.
- Manifest mismatch diagnostics:
  - Manifest verification errors distinguish missing assets, unexpected assets,
    hash mismatches, duplicate basenames, malformed hashes, and disallowed
    paths.
- Support reproduction fixtures:
  - Public-safe support docs and templates ask for AO2 version, platform,
    command, expected result, actual result, evidence path, checksum/manifest
    state, and sanitized logs.

## Public Assets

The release publishes archives for:

- macOS aarch64
- Linux x86_64
- Linux aarch64
- Windows x86_64

The public asset set also includes `SHA256SUMS`, CycloneDX SBOMs, detached
signatures, signed provenance, release readiness JSON, and release-train bridge
evidence.

## Verification

Before installing, download the release assets and run:

```sh
shasum -a 256 -c SHA256SUMS
```

After extracting the archive, run `./verify-release.sh` on macOS/Linux or
`.\Verify-Release.ps1` on Windows. Then install and confirm:

```sh
ao2 version --json
ao2 doctor --json
```

See [Install And Update Guide](../INSTALL.md) and
[Public Release Verification](PUBLIC-RELEASE-VERIFICATION.md) for the operator
workflow.

## Boundaries

AO2 remains local-first. This patch release does not require a Control Plane
update, does not grant release approval authority to the control plane, does
not require provider API keys for the first-run path, does not publish provider
pilot results, and does not update the AO Architecture stack lock.

RSI remains denied.
