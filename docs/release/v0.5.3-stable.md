# AO2 v0.5.3 Stable Patch Release Notes

AO2 `v0.5.3` is a stable patch release for the AO2 `v0.5` line.

Release URL: <https://github.com/uesugitorachiyo/ao2/releases/tag/v0.5.3>

Compatible stable companion:
[AO2 Control Plane v0.1.18](https://github.com/uesugitorachiyo/ao2-control-plane/releases/tag/v0.1.18).

## Why This Patch Exists

Post-`v0.5.2` work closed release-critical Windows authorization and artifact
provenance gaps, added privacy-safe operator troubleshooting bundles, and
completed one canonical GitHub-hosted release path for native Linux, macOS,
and Windows candidates.

## Included Changes

- Physical-Windows worker actions require a short-lived signature bound to the
  exact request, action digest, target node, and trusted public key.
- The outbound-only physical worker retains no inbound HTTP, arbitrary remote
  command, self-hosted public-runner, or credential-change capability.
- A strict, size-bounded import workflow validates sanitized
  `physical_unique` evidence and binds its digest into the hosted promotion
  plan.
- Native hosted Windows now owns the canonical MSVC archive and portable
  lifecycle suite; Linux/MinGW output remains explicitly non-authoritative.
- Privacy-safe troubleshooting bundles redact credentials, environment values,
  private paths, and source fragments while preserving stable problem
  fingerprints.
- Governed issue intake remains draft-only and does not approve, merge, label,
  assign, close, or otherwise mutate issues.

## Public Assets

The canonical hosted workflow publishes native archives for Linux x86_64,
macOS aarch64, and Windows x86_64 together with the immutable promotion plan
and `SHA256SUMS`. Each archive contains its CycloneDX SBOM, build provenance,
release manifest, offline verification record, and installation guidance. The
workflow creates keyless GitHub artifact attestations for every public asset.

## Verification

Before installing, verify `SHA256SUMS`, the GitHub artifact attestation, and the
archive with `verify-release.sh` or `Verify-Release.ps1`. For example:

```sh
gh attestation verify ao2-0.5.3-linux-x86_64.tar.gz --repo uesugitorachiyo/ao2
```

After installation, run:

```sh
ao2 version --json
ao2 doctor --json
```

Rollback remains:

```sh
ao2 install rollback
```

## Boundaries

This release does not grant execution or release authority to the Control
Plane, does not permit arbitrary remote commands, does not require provider
credentials for the public quickstart, and does not authorize broad RSI.
