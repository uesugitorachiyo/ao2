# AO2 v0.5.8 Stable Patch Release Notes

AO2 `v0.5.8` strengthens pre-commit and pre-push quality gates, external issue
repair evidence, installation recovery, archive updates, build identity, and
physical-Windows qualification. AO2 Control Plane `v0.1.19` is its supported
companion release.

## Changes Since v0.5.7

- Adds exact staged, outgoing-commit, and source-head quality execution with
  optional repository hooks and fail-closed Git-state checks.
- Binds external issue repair packs to machine-generated reproduction evidence.
- Hardens install transaction recovery, custom-install doctor discovery, and
  public archive update behavior.
- Adds Rust supply-chain evidence and exact Git-ref build identity monitoring.
- Rejects malformed physical-Windows worker results and binds qualification to
  lifecycle cleanup and worker provenance.

## Supported Archives

- macOS aarch64
- Linux x86_64
- Windows x86_64

Linux aarch64 hosts may use the Linux x86_64 archive under explicit Docker
emulation. AO2 `v0.5.8` does not publish a Linux aarch64 archive.

Verify the downloaded archive against `SHA256SUMS` before installation. The
credential-free fixture workflow remains available for local evaluation.
Rollback uses `ao2 install rollback`; AO2 Control Plane remains a read-only
observer and does not approve or publish AO2 releases.
