# AO2 v0.5.6 Stable Patch Release Notes

release line.

Planned release URL:
<https://github.com/uesugitorachiyo/ao2/releases/tag/v0.5.6>

Compatible stable companion:
[AO2 Control Plane v0.1.18](https://github.com/uesugitorachiyo/ao2-control-plane/releases/tag/v0.1.18).

## Why This Patch Exists

AO2 `v0.5.6` adds a bounded, review-first path from GitHub issue discovery to
an operator-controlled draft pull request. It also hardens the evidence
verification used to prove that the proposed repair stays inside its declared
scope.

## Included Changes

- GitHub issue discovery is bounded by explicit repository, label, state, and
  result-count constraints.
- Repair publication is fork-only and draft-only, with exact source and target
  repository identity checks.
- Recursive duplicate JSON fields are rejected before evidence is trusted.
- Protected paths are derived from the exact proposed diff instead of
  untrusted declared path lists.
- Publication verifies the exact diff, source commit, branch, and pull-request
  contract before reporting success.
- Unix archive installs preserve the evidence required by packaged
  qualification and doctor checks.

## Safety Boundaries

The governed publication path does not merge, mutate the source issue, mark a
pull request ready, request review, create a release, or widen credentials. It
does not require provider API keys and does not grant broader execution
authority.

## Qualification

Publication remains conditional on exact-head native macOS, Linux, hosted
Windows, and outbound-only physical Windows qualification, followed by a
hosted no-publication dry run that binds candidate and physical-evidence
digests. This document does not authorize a live release.
