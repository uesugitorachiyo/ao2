# AO2 v0.5.7 Stable Patch Release Notes

AO2 `v0.5.7` is the next qualified patch candidate for the AO2 `v0.5`
release line.

Release URL after publication:
<https://github.com/uesugitorachiyo/ao2/releases/tag/v0.5.7>

## Changes Since v0.5.6

- Refreshes the execution-receipt compatibility evidence used by AO2 Control
  Plane `v0.1.18`.
- Adds canonical repository agent guidance while preserving the established
  coordination contract wording.
- Binds physical-Windows qualification rows to their worker provenance and
  exact qualified source.

## Supported Archives

- macOS aarch64
- Linux x86_64
- Windows x86_64

Linux aarch64 hosts may use the Linux x86_64 archive under explicit Docker
emulation. AO2 `v0.5.7` does not publish a Linux aarch64 archive.

Publication remains conditional on exact-head native and physical-platform
qualification, a non-publishing hosted dry run, and promotion of the frozen
candidate bytes.
