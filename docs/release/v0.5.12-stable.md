# AO2 v0.5.12 Stable Patch Release Notes

AO2 `v0.5.12` adds the existing qualified Windows outbound worker to the
Windows release archive. AO2 Control Plane `v0.1.19` remains the candidate
companion release; compatibility must be verified from the public pair before
that pairing is treated as current.

## Changes Since v0.5.11

- The Windows archive includes `ao2-windows-outbound-worker.py` and the
  package-root `ao2-windows-worker.cmd` launcher.
- The launcher works from paths containing spaces, forwards arguments without
  reinterpretation, prefers the Windows `py -3.11` launcher, and falls back to
  `python` only when it reports Python 3.11 or newer.
- Hosted Windows archive smoke runs the packaged launcher and one synthetic
  offline physical-host lease validation without a listener, provider call, or
  credential.
- Physical-Windows qualification import reads the git-bound workspace version
  directly from `Cargo.toml`, avoiding platform-specific shell association.

Linux and macOS archives remain unchanged: neither archive contains the
Windows worker or launcher. The worker remains outbound-only and allowlisted;
packaging it grants no execution, approval, provider, promotion, publication,
deployment, beta, RSI, or AO Office Pool authority.

## Operator Requirement

Running `ao2-windows-worker.cmd` requires Python 3.11 or newer. The packaged
launcher reports a single explicit prerequisite error and exits nonzero when a
suitable interpreter is unavailable.

Publication remains governed by the manual physical-Windows and hosted release
workflow gates. This source note does not create a tag, release, or upload.
